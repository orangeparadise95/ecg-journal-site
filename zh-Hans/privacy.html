隐私政策

生效及最后更新日期：2026 年 11 月 11 日

本政策说明 ECG Journal for Polar H10 应用、支持邮箱及本支持网站的数据处理方式。 本应用为独立开发，与 Polar Electro 无关联，亦未获其背书。有关隐私的问题，请联系 ecgjournal.help@outlook.com。

你的心电数据在 iPhone 上处理并保存。应用不会自动将记录或分析结果发送给开发者。 分享导出文件、联系支持以及访问本网站是不同的操作，下文分别说明。

1. 在手机上使用的信息

获得蓝牙权限后，应用通过 Polar BLE SDK 连接你的 Polar H10，接收心电样本、传感器及接收时间戳、 心率、电量和设备信息。记录文件包含设备标识／名称及会话元数据。应用还会保存记录覆盖情况、 你添加的极性标注、实验性分析检查点和报告，以及应用偏好设置。

这些信息用于实时显示、本机记录、回放、标注及可选的端侧分析。应用不要求注册账号，也不包含广告或开发者使用情况分析。 记录及分析功能不会将上述信息上传至开发者服务器或 Polar 云服务。

2. 存储、保护和保留

记录及相关分析数据保存在应用的本机存储中，直至你删除这些数据或移除应用。记录目录不参与自动备份。 文件使用首次解锁后可用的 iOS 数据保护，以支持手机锁定时继续记录；这并不意味着数据对所有能够访问已解锁设备的人或进程均不可见。

记录、分析及导出操作可能产生本机工作文件或副本。已生成的导出文件可能保留在应用存储中。 卸载应用前请导出需要保留的数据。开发者不保留可用于恢复你记录的云端副本。

3. 由你选择的分享

导出内容可能包含敏感的原始心电数据、时间戳、设备／会话元数据、标注和分析报告。 当你在系统分享面板选择“文件”、邮件或其他应用等目的地时，数据会离开本应用。 所选服务或接收方按照其自身条款及隐私规则处理该副本。请仅与可信的接收方分享。 在本应用内删除数据，不会删除已导出到其他位置的副本。

4. 你的控制方式

你可以停止记录、在 iPhone 设置中撤销蓝牙权限、导出数据，或按天删除记录。 正在记录的日期在停止采集前不可删除。按天删除也会移除该日已保存的分析任务及报告。 移除应用会删除其本机应用数据，但不会删除你已分享到应用外部的副本。

开发者无法访问或远程删除仅保存在你手机上的记录。如需使用这些控制功能的帮助， 或对你发送给支持邮箱的个人信息有疑问，请联系支持。

5. 支持邮件

如果你通过邮件联系支持，你的邮箱地址及邮件内容会被接收到 Outlook 邮箱中。 这些信息用于回复咨询、处理支持或隐私请求，而非提供医疗服务。 邮件会保留在邮箱中直至被删除；你可以向同一地址发送邮件请求删除。 请勿发送原始心电记录、病历、密码或不必要的身份信息。

邮件由 Microsoft 及你的邮件服务商处理。Microsoft 的相关做法请参见 Microsoft 隐私声明。

6. 本网站

本静态网站由 GitHub Pages 托管。我们不添加分析工具、广告、跟踪脚本或 Cookie。 GitHub 出于安全目的记录访问者的 IP 地址，即使访问者未登录也是如此。 访问本网站不会上传应用内的心电数据。有关详情请参见 GitHub 隐私声明（英文）。

7. 实验性用途及政策更新

本应用不提供诊断或紧急监护。作出医疗决定前请咨询医生。 如数据处理方式发生变化，本政策将更新并标注新的日期。 本政策提供英语及简体中文版本；如有表述不清之处，请联系支持。
